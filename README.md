# desafio_de_projeto-Controle_de_Investimentos_com_Excel
Entrega de Desafio de Projeto - Criando uma Ferramenta de Controle de Investimentos com Excel

O projeto de criação de uma ferramenta estilo Aplicativo no Excel para simular investimentos em fundos imobiliários;

Utilização de apelido nas fórmulas para melhorar a legibilidade da planilha;

Implementação de chave composta;

Uso de tabela de apoio para organização as informações e simplificar os cálculos;

Aplicação de padrão de design para garantir a uniformidade visual.
